# biomedical_img_analysis
Hybrid biomedical image-analysis pipeline for nuclei microscopy: VLM/LLM-based description (Ollama, llama3.2-vision + phi3), classical Otsu segmentation with regionprops features, a compact U-Net for learned segmentation (Dice 0.996 / IoU 0.992), and a hybrid feature→LLM narrative pipeline with a robustness/corruption extension.
